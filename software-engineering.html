Artifact Overview

The artifact used for this enhancement is the Travlr Getaways full-stack web application that I originally developed in CS 465. Travlr uses the MEAN stack, including MongoDB, Express, Angular, and Node.js.

The application contains a customer-facing website and an administrative Angular interface that communicates with a REST API. The administrative portion allows authenticated users to retrieve, add, and update trip information stored in MongoDB.

Original Functionality

The original version of Travlr was functional, but several parts of the application contained repeated logic and inconsistent error handling. The Angular TripDataService handled API requests for retrieving, adding, and updating trips, but similar code was repeated across several methods.

Authentication headers were also constructed in more than one location, which made the service harder to maintain. The application also relied on older Promise conversion functionality when working with Angular HTTP requests.

Software Engineering Enhancement

For this enhancement, I focused on improving the internal architecture and maintainability of the application instead of only adding a new visual feature.

I refactored the TripDataService so that common API functionality could be reused throughout the application. The base API location and trip endpoint were centralized rather than being repeated in multiple methods.

I also created reusable request and authentication functionality. This reduced duplicated code and made the service easier to maintain. Authentication headers can now be created through a common method instead of being manually constructed for each protected request.

The service was also updated to replace deprecated Promise conversion functionality with a more current RxJS approach using firstValueFrom().

Error handling was improved so that the application can provide clearer information when an API request fails. Errors such as an unavailable server, unauthorized request, API error, or unexpected failure can be handled more consistently.

User Experience Improvements

In addition to the architectural improvements, the application includes confirmation and success feedback when an administrator edits trip information.

These changes improve communication between the application and the user by making it clearer when an update is about to occur and whether the operation completed successfully.
